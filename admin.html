Adicionar evento

⚡ Importar de um link
Cole o link do evento em outro site (ex.: Blacktag) e a gente preenche o formulário sozinho. Nome, data, local, cidade e imagem costumam vir; preço e lote você confere depois.

Eventos no site

Acompanhar lotes na origem

Reabre o link de origem de cada evento importado e compara o lote/preço atual com o que está salvo no site — se mudou, você atualiza com um clique. Como o site ainda é estático, isso roda quando você clica aqui (não fica checando sozinho o dia todo; para alerta automático 24h é preciso backend — me peça quando chegar a hora).

WhatsApps que recebem os pedidos

Cadastre quantos números quiser (só dígitos, com DDI — ex.: 5511996400247). O número marcado como Padrão recebe os eventos em que você não escolher um número específico. Em cada evento, use o campo "WhatsApp deste evento" para direcionar os pedidos daquele evento.

Manutenção

As alterações ficam salvas neste navegador, neste computador — o site (index.html) lê daqui. Antes de mexer muito, clique em "Baixar backup" para guardar uma cópia dos eventos. Quando o site for publicado na internet de verdade, este painel precisará de um banco de dados (me peça quando chegar a hora).
